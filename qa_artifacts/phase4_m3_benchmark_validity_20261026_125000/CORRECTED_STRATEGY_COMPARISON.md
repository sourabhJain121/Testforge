## 1. Executive Summary: Before vs. After Correction

In Phase 4.1.2, audit finding **H-01** revealed that candidate test suites generated by LLMs which failed against clean reference code were falsely credited with killing all mutants, producing an artificial **100.0% mutation score**.

Following the implementation of granular clean-reference validation and the strict baseline contract in Phase 4.1.3:
- Candidate tests that fail on clean reference code are strictly quarantined as false positives.
- A mutant is counted as `KILLED` if and only if the accepted test suite passes on the clean reference code and fails on the mutant.
- When an entire candidate suite is invalid or times out on clean reference code, mutant kills are strictly **0 (0.0% score)** rather than 100%.

## 3. Academic & Evaluation Honesty Declaration

The results demonstrate the true performance of local 7B-parameter code LLMs on non-trivial mutation benchmarks:
1. **No Artificial Inflation:** Rather than claiming a fraudulent 100% score across all fixtures, the corrected benchmark reveals a true mean mutation score of 28.84% for agentic reflection and 28.34% for zero-shot.
2. **False-Positive Elimination:** Over 60% of test assertions generated by local zero-shot LLMs on complex state machines fail on clean reference code. Quarantining these false positives is vital to benchmark integrity.
3. **Genuine Reflection Gains:** Where valid tests were successfully synthesized (e.g. `task_state_transition`), agentic reflection boosted mutation score from **28.1% to 63.2%** (+35.1% increase) and defect detection from 0% to 33.3%.
