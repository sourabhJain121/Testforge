**CAUSED BY A GENERATOR FALLBACK DEFICIENCY (UNIVERSAL EXCEPTION SWALLOWING).**  
The 0% score was not caused by a failure of the mutation engine to inject faults or execute tests. It was caused by the fallback test generator in `testforge/agents.py` (lines 910–918), which wrapped all synthesized test calls in `try: ... except Exception: pass`.  
Because `except Exception: pass` suppresses all assertion errors, type errors, arithmetic faults, and exceptions, every mutant exited pytest with return code `0`. Under strict mutation testing rules, any mutant that passes the test suite must be classified as `SURVIVED`.
